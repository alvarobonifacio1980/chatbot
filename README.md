# chatbot

O projeto chatbot é um assistente virtual focado em responder perguntas sobre o mercado financeiro brasileiro. Utilizando inteligência artificial e memória de conversas, ele oferece respostas curtas e precisas sobre temas como renda fixa e renda variável. Desenvolvido com Streamlit e LangChain, o chatbot proporciona uma experiência interativa e personalizada para usuários interessados em investimentos no Brasil.
